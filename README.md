## 📌 About

This repository documents my hands-on journey into **Agentic AI and LLM Engineering** — from the GenAI foundations required to understand modern LLM applications to building **RAG systems, AI agents, stateful workflows, multi-agent systems, and MCP-based integrations**.

The emphasis is on understanding how modern AI systems work beyond a single LLM call: how they **retrieve information, use tools, maintain state and memory, make decisions, interact with external systems, and coordinate complex workflows**.

### 🎯 Goals

- Build strong foundations in Generative AI and LLM Engineering
- Design practical RAG and retrieval-based systems
- Build AI agents with tools, memory, state, and reasoning workflows
- Explore multi-agent architectures and human-in-the-loop systems
- Connect agents with external systems using MCP and APIs
- Build reliable, production-oriented agentic AI applications
